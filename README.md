# Data Structures and Algorithms

A collection of LeetCode solutions organized by problem number and title. Solutions are primarily written in C, with selected problems implemented in Python.

## Topics

- Arrays and strings
- Linked lists
- Binary search
- Trees and binary search trees
- Sorting and searching
- Sliding window
- Recursion and basic mathematics

## Structure

Each problem has a separate folder containing its solution and a short problem README where available.

```text
dsa-problem-solving/
├── 0002-add-two-numbers/
│   ├── 0002-add-two-numbers.c
│   └── README.md
├── 0004-median-of-two-sorted-arrays/
└── README.md
```
